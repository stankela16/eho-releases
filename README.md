# Eho — izdanja

Javna polica za instalacije aplikacije [Eho](https://eho.vercel.app), glasovnog diktata napravljenog za srpski.

- **Preuzimanje:** najnovija verzija je na stranici [Releases](../../releases/latest).
- **`appcast.xml`:** spisak verzija koji aplikacija čita da bi ponudila ažuriranje (Sparkle).

Izvorni kod aplikacije nije u ovom repou.
